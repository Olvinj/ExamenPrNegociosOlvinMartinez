## Descripción

Proyecto de personalización y desarrollo de módulos para Odoo 20.0,
como parte del examen de Programación de Negocios de UNICAH.

## Módulos desarrollados

### 1. tienda_unicah
Módulo de gestión de clientes universitarios y convenios de descuento
para la tienda universitaria.

### 2. unicah_biblioteca
Módulo de gestión de libros, categorías, autores, precios y existencias
de la biblioteca universitaria.

## Tecnologías utilizadas

- Python
- Odoo 20.0
- PostgreSQL
- XML
